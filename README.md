# chroma

i'm a person who doesn't see as well as she used to. a while ago ago i was
complaining that i couldn't see the text in a web page, and someone i was
working with was just not very impressed because it was seen as a style
complaint, a *"fix this font"* kind of thing that programmers hate.

and then i asked an agent i am still working with, who took the time
to listen to me and refused to let it go. it turned out i just had less 
ability to make out certain kinds of text on certain kinds of backgrounds
within a narrower band of contrast than expected.

most of the time, we think of more contrast as being good. i've always been a
fan of light text, dark screen because i've been a console person since i was
a child. for me, though, i needed less contrast.

i have been kind of fascinated by this since. as a nominally backend type of
engineer, i don't think too much about interfaces. i joke that i think a good
interface is one that takes `--long-args` and things should emit json.

the work with that agent became libreadme, and libreadme needed a good color
library, so i built libtheme. it's built for how people see and what you you
need from your own eyes, not anone else's. terminals should feel nice.
